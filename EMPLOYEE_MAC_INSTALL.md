# Install PROWRAP ISO 24817 Calculator v1.3 on your Mac

Before employee installation or manual packaged-app acceptance testing, confirm that the Mac is an Apple Silicon M4/M5 model running macOS 26.5.2 or later. This built release does not run on Intel Macs, and compatibility with older macOS versions is not claimed.

You do not need an internet connection or Python installation. The v1.3 calculator works offline, and your calculator data stays on your Mac.
Its distinct release bundle identifier is `com.protapglobal.prowrap.iso24817calculator.v13`.

## Install and open

1. Copy `PROWRAP-Calculator-v1.3-macOS-arm64-M4-M5.zip` to your Mac and double-click the ZIP file.
2. Drag **PROWRAP ISO 24817 Calculator v1.3.app** to your **Applications** folder. Its distinct name allows it to remain installed beside other releases; do not rename it.
3. The app is unsigned, so the first-launch warning is expected. For the first launch, Control-click **PROWRAP ISO 24817 Calculator v1.3.app**, choose **Open**, then confirm **Open**.
4. Wait until the small launcher window says **Ready**. The calculator normally opens in your browser automatically. If it does not, select **Open Calculator** in the launcher window.
5. Leave the small launcher window open while you are calculating. It keeps the local calculator running.
6. When you are finished, choose **Quit** in the launcher window.

## Support boundary

The v1.3 calculator runs only on your Mac at a local address (`127.0.0.1`) and does not need the internet while in use. Do not change macOS security settings to open it: use the normal Control-click > **Open** first-launch step above. This employee-install procedure does not overwrite or redeploy any existing calculator or CalcBatch project.

If the launcher does not reach **Ready**, or **Open Calculator** does not open the calculator, quit the launcher and open it again using the same Control-click > **Open** method. If the issue continues, contact PROTAP support and include a screenshot of the launcher window.
